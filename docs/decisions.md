| 2026-11-07 | Code | Plain HTML, CSS, JavaScript ES modules. No framework, no build step | Every file stays readable for a beginner |

| 2026-11-07 | Testing | Node's built-in test runner (`node --test`), no test libraries. GitHub Actions runs tests on every pull request (Phase 2) | Catch bad puzzles before they ship |
| 2026-11-07 | Privacy | No analytics, no ads, no external network requests, no links out of the app, no child names anywhere in the repo | A child holds this phone |
| 2026-11-07 | Workflow | After the first commit, never commit directly to `main`; every change goes through a branch and a pull request | Teaches the professional workflow and gives the owner a review step before anything goes live |
| 2026-11-08 | Game modules | `generate(seed, words)`: the page loads the word list once and passes it in, instead of each game loading files itself. Replaces `generate(seed)` above for word games | Keeps game files simple and testable in Node without a browser |
| 2026-11-08 | Word guess | Any letters of the right length count as a guess; there is no "not a real word" rejection. After 6 tries the word is shown kindly | A short answer list would wrongly reject real words a child knows; rejection discourages early readers |
| 2026-11-08 | Word guess | Daily word comes from `level-2.json`: four-letter words with one short vowel and a blend or letter pair (frog, fish, jump). `level-1.json` (three letters) stays for later use | Owner's choice: four-letter words are the right challenge |
| 2026-11-08 | Keyboard | QWERTY layout. Letter keys are about 31px wide (10 fit across a phone) and 58px tall. Overrides the 48px tap-target rule for keyboard keys only | Owner's choice: matches the keyboards the player already sees. Taller keys make up for the narrower width; revisit if keys get missed in the play-test |
| 2026-11-08 | Home screen | The first screen is a game picker: Mystery Word is playable; Letter Wheel, Tile Match, and Maze show as "Coming soon" until built. Each screen has its own address (`#mystery-word`) so the phone's back gesture works. Pulled forward from Phase 2 | Owner's choice: the app should open on a choice of puzzles |
| 2026-11-08 | Progress | **Replaced by the Streak row below.** For now, progress lasts only while the page is open (leaving a game and coming back keeps the guesses; finished games show "Done ✓"). Saving progress and the streak in localStorage stays in Phase 2 | Keeps this change small |
| 2026-11-08 | Word guess | After a wrong 5th guess, a clue shows the word with one letter missing (for example `? E L T`), in the last row and the message. The missing letter is one not yet found in the right spot | Owner's choice: the last try should be fairly easy to get, so most days end in a win |
| 2026-11-08 | Streak | A day counts when at least one puzzle is finished (found or revealed). Same-day repeats count once; missing a day starts over at 1 with no message about it. Saved in localStorage under `kids-puzzles.progress`, with 14 days of finished-puzzle history | Rewards coming back without penalties. Counting any puzzle keeps it encouraging once there are several games |
| 2026-11-08 | Celebration | Finishing a puzzle shows a card in the middle of the screen (star, "You did it!", streak) with falling stars. Falling stars and pop-in are skipped when the phone is set to reduce motion | The end-of-puzzle message was below the keyboard and needed scrolling; a centered card is always seen |
| 2026-11-08 | Home screen | Lineup: Mystery Word, Number Pyramid, Letter Wheel (coming soon), Magic Square (coming soon). Tile Match and Maze are dropped | Owner's choice: math games based on the printed puzzle packs, blending engagement with real numeracy practice |
| 2026-11-08 | Math range | Math games use numbers up to 100 | Owner's choice: matches the two-digit work in the printed packs |
| 2026-11-08 | Number Pyramid | 4-3-2-1 pyramid, top brick 40 to 100, 5 blanks with at least one in the bottom row (subtraction thinking). Every blank can be worked out step by step; checked for every day in tests. Hints: the rule after 1 miss, the number sentence after 2, and the brick fills itself in after 3 | Practice with a ceiling on struggle: no guessing needed, no getting stuck |
| 2026-11-08 | Magic Square | 3x3 grid of evenly spaced numbers (step 1 to 5) in the classic magic square pattern; every row, column, and diagonal adds to the target (30 to 99). 4 blanks, each solvable from a line with two known squares; checked for every day in tests. Same hint ladder as Number Pyramid, plus the hinted line glows | Practices adding three numbers and "what's missing" thinking |
| 2026-11-08 | Magic Square | Answers are typed on the number pad, not placed as tiles | With only 4 blanks, a tray of 4 tiles could be solved by trying each one; typing requires the adding |
| 2026-11-08 | Keyboard | A laptop keyboard only reaches the game that's on screen | Two number games open in one visit would otherwise both take the same keypresses |
| 2026-11-08 | Letter Wheel | 6 letters: one in the middle that every word must use, five around it. Each tile can be used once per word; words are 3 or 4 letters. Today's words (4 to 8) are every word from the level 1 and level 2 lists the wheel can spell, so a correct list word is never turned away; checked for every day in tests | Spelling practice with only owner-reviewed answers |
| 2026-11-08 | Letter Wheel | A real word that isn't on the lists gets "Good word! It's not one of today's," never "wrong." Hint reveals one letter at a time, shortest word first, never a whole word | Encouraging; hints never give away the finish |
| 2026-11-08 | Maze | 7x7 "perfect" maze (exactly one route from start to star), new each day. Trace with a finger: walls stop the path silently, sliding back erases it, tapping a square on the path cuts back to it. A finger that jumps more than 2 squares is ignored so the maze never walks itself. Hint lights the next 3 squares of the route; a dead end says "trace back" | Finger tracing from the brief; no penalties for wrong turns |
| 2026-11-08 | Home screen | Cards are more compact so 5 to 7 games fit; the home screen may scroll a little, game screens never do | More games |
